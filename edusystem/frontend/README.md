# EduLMS Frontend

Frontend ReactJS + Vite cho he thong quan ly lop hoc, sinh vien, hoc phan, bai tap, diem so, tai lieu hoc tap va tien do hoc tap.

## Cai dat

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Backend mac dinh khi chay dev: `/api`, duoc Vite proxy sang `http://localhost:8080/api`.
